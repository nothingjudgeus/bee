# 源码编辑地图

所有显示和交互源码均在包中，未压缩混淆。没有绑定必须续费的编辑器。

| 区域 | 入口 | 修改方式 |
|---|---|---|
| 站点标题、SEO 描述、导航与页脚 | dist/index.html | 改对应文字、meta 与链接 |
| 主页排版、随笔列表、文章阅读、搜索 | dist/site.js | home、article、route 等函数 |
| 博客主题 | dist/site.css | 文件末尾为新版暖纸色覆盖 |
| 数学标题与导航、通用弹窗 | dist/study.html | 改页面壳层 |
| 数学首页与画廊 | dist/atlas.js | renderHome 与 artFiles |
| 图谱坐标和默认排布 | dist/atlas.js | defaultGraph、renderMap、createMap |
| 题库筛选、详细解析与复盘 | dist/atlas.js | renderProblems、renderProblem、renderReview |
| 方法训练 | dist/atlas.js | renderPractice 及题型/方案映射 |
| 数学内容 | dist/atlas-data.js | modules、nodes、exercises |
| 数学界面视觉 | dist/study.css | 新版覆盖样式；study-base.css 为完整基础结构 |
| 文章持久发布内容 | dist/content/posts.json | 改 JSON 或用 publish_posts.py 合并 |
| 图片资源 | dist/assets | 替换文件后核对引用路径，保留授权说明 |
| 声音与动效 | dist/atmosphere.js / .css | 调整旋律合成、音量、选择弹窗与运动规则 |
| 本地预览 | scripts/serve.py | 默认仅监听本机 8080 |
| 自动发布 | .github/workflows/deploy.yml | main 推送到 GitHub Pages |

颜色优先修改 study.css / site.css 的变量与末尾覆盖。不要仅替换画作文件扩展名而不改路径。SVG 可以用矢量工具修改，JPG/WebP 可以用图片软件替换。字体使用系统回退，商业字体文件未打包。
