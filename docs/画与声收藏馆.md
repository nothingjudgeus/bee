# Bee · 画与声收藏馆

## 入口和功能

- 网站导航「画与声」进入 dist/atelier.html。
- 画集 38 幅：5 幅原有本地图像，33 幅芝加哥艺术博物馆公有领域馆藏，采用官方 IIIF 远程图像地址。
- 画集支持画家筛选、搜索、放大、上一幅/下一幅、来源跳转、设为书房首页封面。
- 音乐集 12 首浏览器实时合成的原创氛围乐曲；支持选择、试听、切歌、暂停和音量。
- 首次进入音乐集不自动播放；浏览器要求用户主动交互后才能发声。

## 如何新增绘画

在 dist/atelier-data.js 的 artworks 数据中增加唯一 id，并填写 artist / title / year / src / source。新增图片可放在 dist/assets/ 并填写 assets/文件名；远程图像应核对画作许可和馆藏来源。芝加哥艺术博物馆官方 API 文档：https://api.artic.edu/docs/ 。外部远程图像需要网络连接。

## 如何新增原创曲目

在 dist/atelier-data.js 的 tracks 增加唯一 id，以及 title、subtitle、timbre、step、chords、melody 和 art；音高使用 MIDI 数字。支持 glass、felt、plucked、air 四种基础音色。当前是浏览器实时合成，并非音频文件；真实音乐录音需单独引入受许可音频资源及播放器支持。

## 选择与同步

选择画作会写入浏览器本地 bee_art_choice，返回主站首页后作为封面显示。选曲会写入 bee_music_choice；主站与数学书房会使用该曲编配作为下次播放的背景音乐。音量沿用 bee_volume，静音状态沿用 bee_sound。设置可从主站「备份与设置」导出、恢复，不会自动更改所有访客的默认选择。

## 版权和部署

33 幅新增馆藏图像经芝加哥艺术博物馆官方数据标记为 is_public_domain=true；馆藏来源和站点条款由该馆提供。图片通过外部服务器显示，未复制成 GitHub 二进制文件。已有五幅画作来源见 ART_CREDITS.md。12 首为本网站编配的原创合成氛围音乐，无第三方商业录音。

提交前运行 node scripts/validate.mjs；push 到 main 后由既有静态发布流程自动发布 dist/。如增添条目，应相应更新页面内静态数量和脚本数量检查。
